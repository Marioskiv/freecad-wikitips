## Rules for this repo
- `data/` is generated by `tools/build_data.sh`; never hand-edit `data/commands.json`.
- After any code change run the offline test (`tests/run_popup_test.py`, see README) and look at the PNGs it writes.
  Also run the real-FreeCAD test `tests/freecad_gui_test.py` (how: `docs/notes/memory.md`); it must say PASS.
- Work on a branch and open a PR; never push to `main`. Marios has allowed Claude to merge its PRs
  into `main` once the real-FreeCAD tests pass (see memory.md).
- The addon must never break FreeCAD: every event-filter path is wrapped in try/except; keep it that way.
- No pip dependencies inside the addon: Marios's FreeCAD Python has **no SSL**, so the Addon Manager cannot install Python packages for him (see freecad-findings.md).
- Update `docs/notes/` at the end of every session: what changed, what was verified, what is open.
